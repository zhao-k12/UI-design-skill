# V0.2 默认字体 Button 改编保真门 0.2.2

适用范围仅为锁定的 View UI Plus `action.button.primary.medium` 静态“查询”实例、Figma Inter Regular 400 与 Penpot sourcesanspro regular 400 的两个原生候选。旧版 Fidelity Gate 0.1.0/0.2.0 和 V0.1 Registry 均不变。

用户已批准新版本平台默认字体改编。官方来源的结构、内容、非文字填充/描边、半径、padding、尺寸、字号、字重和行高仍须逐项匹配；字体家族和由它产生的文字轮廓允许在两个平台分别变化。独立原生读取必须证明主组件、实例关联、目标文件身份、字体绑定和文字可编辑。首次及重复原生 PNG 必须逐字节一致，SVG 必须独立导出并与候选内容相符。

像素检查只豁免官方文字矩形（每边扩展 2 px）和 4 px 圆角的四个 5×5 角区。其他像素要求完全一致，直边没有豁免。角区差异的来源和候选颜色都必须落在已锁定蓝色 `#2D8CF0` 与白色的线性覆盖关系内，RGB 量化残差不得超过 2；这检查颜色身份，不设总差异像素比例。文字区域逐字检查亮色笔画存在、非实心及未触碰文字边界；人工视觉复核绑定实际 PNG/SVG 哈希，确认 Unicode“查询”两字可读、无豆腐字和裁剪。不同字体的笔画覆盖量不与旧字形强制相等。

准入报告可确认此 Button 配置的双平台原生保真；报告必须同时记录 `effectiveCjkFontIdentity=UNVERIFIED`，不得把 Text API 的字体家族误称为实际中文回退字体。此保真门不授权其他文字、尺寸、状态、组件或完整页面。只有报告 PASS 且另经版本化 Registry 与 Adapter 绑定迁移，才能用于正式页面。
