# V0.2 默认字体 Tabs：Figma 单端质量核验

范围仅为 View UI Plus 1.3.24 `navigation.tabs.line.overview` 固定静态配置：两个标签“概览”“详情”，选中概览，仅显示“概览内容”，320×73px。Figma 使用当前文件默认 Inter Regular 14/21；实际中文回退字体身份无原生证据时记为 `UNVERIFIED`。

Figma 必须保留可编辑文字、原生主组件与真实关联实例。标签栏 320×36px，两标签 60×37px，x=0/76；底线 y=35、蓝色选中线 x=0/y=34、60×2px；内容从 y=52 开始。色值 `#2D8CF0`、`#DCDEE2`、`#515A6E` 绑定已锁定的来源变量。未选中“详情内容”不得在静态画布上出现。

官方与 Figma 图片均为 320×73px，不缩放、不平移；Figma 透明像素先合成到白底。排除标签及正文三个文字区域后，非文字像素必须逐像素完全一致。三个可见文本区应分别有至少 100、100、250 个深色像素且位于各自框内。独立复验的原生读回、PNG/SVG 应与候选一致，重复 PNG 逐字节一致；人工视觉复核绑定复验 PNG 哈希。

用户决定暂缓 Penpot，故 PASS 只表明 Figma 单端 QA。`admissionEligible=false`，不可登记正式 Registry 或宣称 V0.2 发布就绪。
