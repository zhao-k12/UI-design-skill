# V0.2 默认字体 Input 的限定保真政策

仅适用于 View UI Plus 1.3.24 `form.input.default.medium` 的静态、空值、240×32 Input，固定占位文字“请输入姓名”。Figma 使用目标文件观察到的 Inter Regular 400；Penpot 使用新目标文件观察到的 sourcesanspro regular 400。这个字体改编沿用用户要求的两端平台默认字体，不能套用 V0.1 官方字体栈的逐字形相同要求。

固定非文字区域必须与官方浏览器截图逐像素一致，范围排除占位字形区（x=5..99、y=3..28）和四个 5×5 圆角。圆角需保持 `#DCDEE2` 与白色之间的抗锯齿混色，最大通道残差不超过 2；白底、1px 内描边、4px 圆角、7/4px padding 和 240×32 外框仍按来源精确校验。五个占位字各须有可见、完整、未裁剪的灰色字形，两端独立原生重复导出须逐字节相同。SVG 必须保持结构颜色，Figma 需有轮廓路径，Penpot 需保留准确文本和默认字体绑定。

Gate PASS 只表示这个固定占位样张具有准入资格，不扩大到任意占位文字、非空值、其他尺寸、交互状态或动态输入；Registry 另行设计范围约束。中文实际回退字体身份若无法原生验证，记录 `UNVERIFIED`，不得推断名称。
