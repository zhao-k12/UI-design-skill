# V0.2 默认字体 Modal：Figma 单端质量核验

范围仅为 View UI Plus 1.3.24 `overlay.modal.notice.open` 固定通知内容框：标题“提示”、正文“操作已完成”，无关闭按钮与页脚，内容框 320×104px。Figma 使用当前文件默认 Inter，保留可编辑文字、原生 Modal 主组件、关联实例、来源颜色与阴影。

官方截图为内容框裁切；Figma 导出包含阴影，为 344×128px，内容框位于 (12,8)。Figma 透明像素先合成白底，再精确裁切 320×104 内容框，不做缩放。排除标题与正文文字区域后，只将 6px 圆角涉及的四个 7×7px 角区单独记录；其余非文字像素必须逐像素一致。角区差异不作为非角区像素放行，须另有原生圆角/阴影结构读回与人工视觉复核。标题至少 200 个、正文至少 300 个深色像素，字形完整位于文字范围。独立原生读回和 PNG/SVG 与候选一致，重复 PNG 逐字节一致；视觉复核绑定复验 PNG 哈希。
