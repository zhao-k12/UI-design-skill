# V0.2 默认字体 Table 的限定保真政策

仅适用于 View UI Plus 1.3.24 `data.table.default` 的静态无表头、无外边框、无条纹三列三行样张。列为姓名、状态、角色，宽度各 464；三行固定为张三/启用/管理员、李四/启用/编辑、王五/停用/访客。外框 1392×144，行高 48。Figma 使用目标文件默认 Inter Regular 400，Penpot 使用替代验收文件默认 `sourcesanspro` regular 400；字号 14，行高 21。中文实际回退字体身份保持 `UNVERIFIED`。

九个文字区域允许平台默认字体与官方网页字体栈形成字形差异，但须逐字完整、可读、无裁剪。文字以外区域，包括白色单元格背景、`#E8EAEC` 行分隔线和 `#DCDEE2` 底边线，必须与官方浏览器截图逐像素相同。文字区限定为每行 y=10..36、58..84、106..132 与每列 x=14..78、478..542、942..1006 的交集；扩大该豁免区须重新验收。

主组件与实例绑定及 26 节点原生层级须经独立读取验证。两端原生 PNG 独立重复导出必须逐字节相同。SVG 须来自同一原生主组件：Figma 的九个文字轮廓为九条有 `#515A6E` 填色的非空路径；Penpot 必须保留九个准确 Unicode 文本和 `sourcesanspro` regular 400 字体声明。视觉复核需绑定 PNG 哈希。

Gate PASS 只提供上述固定内容样张的准入资格，不包含其他数据、列、表头、尺寸、交互或动态表格。Registry 准入另行执行。
