# 首次端到端原型语义复核

来源仍是用户已选择冻结的“姓名／状态／角色”列表。没有改变原型文字、表格数据或原生保真基线。来源字节 SHA 和每条引用的 Unicode 范围已验证；解析报告保持 Review，尚未填写人类 approved 回执。

| 区块 | 从原型提取的内容 |
| --- | --- |
| 页头 | 用户管理标题；已验收设置图标 |
| 查询区 | 姓名输入，占位“请输入姓名”；状态选择，当前静态“启用”；范围文字“查看用户信息”；“查询”按钮 |
| 列表区 | 用户列表标题；“导出”文字与已验收下载图标；姓名／状态／角色三列表格；汇总“共 3 位用户” |

表格三行固定为：张三／启用／管理员；李四／启用／编辑；王五／停用／访客。

语义结构是3个 Section、2个字段、1个明确按钮、1个数据区域、5项静态内容，共9项。标题与设置图标在一项页头内容中组合；导出在原型中称“操作”，没有注明按钮组件，因此保留为文字与图标的静态操作显示，不擅自改成蓝色按钮。不增加重置、新增用户、邮箱列、状态选项、跳转或点击业务逻辑。

原始观察、解析、Page Tree 及当前 Review 报告在 examples/acceptance-prototype。按项目 SKILL 的前一质量门规则及 validators/structure/gate.py 的 `Human semantic review receipt required`，这一具体语义提取获批后，才冻结结构并执行其依赖的正式布局和平台写入。
