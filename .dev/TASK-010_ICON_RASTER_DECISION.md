## 请求批准的唯一扩展

仅对现有两份 SHA 锁定官方图标，允许来源几何与完整路径证据已通过、SVG 重现逐字节一致时的**原生 PNG 向量边缘栅格差异**，并同时要求：

1. 原始来源、原生完整capture、PNG/SVG、探针与检查脚本哈希全部绑定；不得仅凭手工 PASS 字段准入。
2. 继续执行已批准的精确来源 Float32 命令校验，24×24、全部样式/效果/真实主组件严格检查。禁止微移、改路径、换图片或 detach。
3. 所有 PNG 差异必须位于实际原生 SVG 重现图的既有 AD-017 edge_band 内；带外一个差异也拒绝。图标仅在自己的24×24范围允许该边缘检查，不放宽整页其它区域。
4. 原生有效像素必须严格为黑色，图像非空；来源/原生前景及空白连通区域数相同，前景各区域包围盒完全一致。只对透明边缘覆盖值比较保留差异；不得用像素总比例、最大通道差或几何容差阈值准入。
5. 保存两次独立原生 PNG 一致证据及所有失败回执，明确第二次capture为PARTIAL。生产截图始终使用完整主组件原生 PNG。
6. 新检查先通过错误来源/路径/效果/PNG/缺区域/空图/错色/带外差异的拒绝测试，再实际准入。列表页仍必须证明真实图标实例与主组件关系及独立原生导出；本批准不自动完成TASK-010。

Core/UI-IR、逻辑 Registry、四个已准入组件的规则和Figma证据均保持原样。不会扩展到其它图标或一般矢量图。
