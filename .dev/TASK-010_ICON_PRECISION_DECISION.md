## 已完成的实测

两份原始官方 Remix SVG 的字节及来源指纹未修改。第一次将主组件移至远处后，路径坐标产生额外舍入。随后在原点恢复原始路径，Penpot 的实际 API 回读和原生 SVG 仍将各坐标保存为 Float32。

原点回读的所有有序路径命令严格等于原始 SVG 各坐标的 IEEE-754 Float32 编码。设置图标56条命令、下载图标17条命令；实际最大坐标差分别为 0.0000009521484365393462 和 0.00000034179687524726887。这里记录实测差值，**不提议以这些值作为容差阈值**。

原始官方 SVG 与恢复后的原生 SVG 在同一冻结浏览器、24×24、黑色/白底上下文中的 PNG 逐字节一致。证据见 `adapters/penpot/metadata/icons-native-v1/precision-diagnostic.json` 与 `svg-probe.json`，原始回执、恢复操作、失败回执均保存。

## 建议批准的唯一补充

仅对这两份来源锁定的 Remix 路径，允许显式标记 `source-derived-float32` 几何归一化，并要求同时满足：

1. 原 SVG 字节与官方 Registry SHA 完全一致；范围仅限已观察的 M/L/C/Z 有序路径。
2. 命令、轮廓顺序、闭合、点数不变；每个实际坐标必须精确等于该来源坐标的 Float32 编码。拒绝任意阈值匹配、手工微移或再取整。
3. 24×24 viewBox、填充、填充规则、透明度、变换、描边和真实主组件身份严格验证。
4. 原始 SVG 与原生 SVG 的浏览器重现 PNG 必须逐字节一致。
5. 保留原生完整 PNG/SVG、源文件和独立回读；真实列表页实例仍须再次验证。不得以浏览器诊断 PNG 替代原生生产 PNG。

**源坐标与原生坐标不声称精确相等**；报告必须保留原始坐标比较 FAIL/差值及编码比较结果。Core/UI-IR、逻辑图标 Registry、四类组件既有规则和证据不变。
