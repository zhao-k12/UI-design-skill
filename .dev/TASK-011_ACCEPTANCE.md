# TASK-011 — Prototype Semantic Parser

日期：2026-10-08。范围：AI 语义观察、来源绑定契约、确定性证据核对及分析输出。

## 实际验收

对 `examples/prototype-semantic/prototype.txt` 的静态文字原型进行语义观察，保存
`observations.json`，实际运行解析器得到 `prototype_analysis.json`。该文件为专门
编写的验收原型，不冒充用户提供的截图或平台实际读回。

逐项核对源文本与输出：页面为用户管理，主要任务为查找用户并查看列表；区块为
筛选、工具、数据结果、范围说明。姓名和状态为字段，查询/重置/新增用户/导出
为按钮；用户列表列与示例行分别保存为数据展示区域和静态内容。状态选项未提供，
明确保存问题，未猜测选项。完整点击行为没有推断。七项输出类别均存在且有原文证据。

每条证据均通过源文件字节 SHA-256、原始换行下的字符范围和精确引文核对。
输出符合独立 analysis schema。语义判断与来源引文校验分开：结果保留 Review，
不自动批准或进入后续结构生成。没有创建 Page Tree、布局或最终设计。

## 验证

7 个新测试覆盖语义输出、输出契约、不修改输入、未知信息保留、禁止设计字段、
来源篡改、越界证据、缺失/重复引用与 ID、目录逃逸、缺失语义类别和禁止自动批准。
另运行 Core 架构检查及全项目 Python 回归，最终结果记录在开发状态。

## 能力边界

AI 阅读原型并生成语义观察；程序校验并保存分析。当前输入为 UTF-8 文字原型，
截图需先核对转录，没有自动 OCR 或模型供应商调用。证据一致不等于语义正确，
仍需语义复核。示例含未知项，因此其 Review 状态不表示解析器任务验收失败，
也不表示这个示例已准许进入 TASK-012。
