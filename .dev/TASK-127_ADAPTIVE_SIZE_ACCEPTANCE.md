User direction: fixed-width and fixed-height values from one source screenshot must not be component admission conditions. This task introduces a separate Figma-only V0.2.9 path. V0.2.8 and all earlier task inputs, reports and bindings remain unchanged. Penpot remains deferred.

The 19 V0.2.9 component content scopes omit `width`, `height` and per-column `width`; their old dimensions remain in source Component IR only as measurements. They still check valid geometry, Cell fit, source content, component binding, overflow and native readback.
