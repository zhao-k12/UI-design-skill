# 明细页运行时验证补充

## 背景与静态表格

带侧栏的页面壳拥有整列白色背景；主内容区拥有浅灰背景。侧栏导航保持视口高度和粘性，不将其元素高度误认为整页背景覆盖范围。声明 `surface-cover` 时绑定实际背景拥有者。

静态导出移除脚本后，普通表格的表头与正文共用正文滚动容器，避免依赖已移除的脚本同步。已采用内容适配网格和共享外层滚动的表格保持原策略。普通列与固定列均应在窄、宽视口横向滚动后检查对应列边界。

隐藏的页签内容不参与可见模块间距、关闭图标和标签几何检查；激活内容仍须检查。

## 机器计时边界

`qa.json.machineTiming` 记录导出器模块加载后的墙钟时间，分解资源准备、浏览器启动、布局准备、三态截图与几何/签名采集、静态与响应式检查、审核拼图和浏览器关闭。它不包含模型识图、Tree 编写、Python 准备/编译和实际视觉复核，不能用来证明端到端五分钟目标达成，也不能在无对照时宣称加速率。

这些检查不证明原图观察真实性、数值业务正确性或未覆盖页面的可靠性。
